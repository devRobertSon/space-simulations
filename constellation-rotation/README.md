# 🌠 별자리의 일주 회전 (Diurnal Rotation of a Constellation)

**정동(正東)에서 떠서 정서(正西)로 지는 별자리**가 특정 위도의 관측자에게
하늘을 가로지르며 **어떻게 기울고 회전해** 보이는지 보여주는 교육용 시뮬레이션입니다.
빌드 없이 브라우저에서 바로 동작하는 순수 HTML/CSS/Canvas 페이지입니다.

> ⚠️ 이 시뮬레이션은 **지구의 자전**에 의한 **하루(약 24시간)** 동안의 변화만
> 반복합니다. 계절 변화나 별의 실제 고유운동은 포함하지 않습니다.

## 핵심 개념

별이 **정확히 정동에서 떠서 정서로 지려면 적위(δ)가 0°**, 즉 천구 적도 위에 있어야
합니다. 이 별자리(기본: 오리온자리)는 천구 적도에 걸쳐 있어 정동出·정서沒하며, 위도에
따라 하늘에서의 **기울기와 회전**이 달라집니다. 적위를 바꾸면 뜨는·지는 방위도 변합니다.

## 세 가지 뷰 (모두 같은 상태에 연동)

| 뷰 | 설명 |
| --- | --- |
| 천구 (바깥에서 본 모습) | 천구 적도 위의 별자리와 자전하는 지구·관측자·지평선. 드래그로 시점 회전. |
| 반구(하늘 돔) — 사람이 가운데 | 관측자를 둘러싼 하늘 돔에서 별자리가 동에서 떠 서로 지며 회전. 화살표는 바라보는 방향. |
| 하늘 평면 — 바라보는 방향 | 관측자가 선택한 방향(동/서/남/북)을 바라볼 때 보이는 하늘. 별자리가 기울며 회전하는 모습을 정면에서 봄. |

## 조작

- **관측자 위도**(−90°~+90°) 슬라이더
- **별자리 중심 적위**(−80°~+80°) 슬라이더 — 0°일 때 정동出·정서沒
- **바라보는 방향**: 북 · 동 · 남 · 서 버튼 (하늘 평면 뷰의 시선 방향)
- **시간**: 재생 / 일시정지 / 정지, 경과 시각 슬라이더(0~24h), 재생 속도(0.25×~8×)
- 모든 슬라이더 값은 숫자를 **클릭하면 직접 입력**할 수 있습니다.

## 로컬 실행

```bash
python3 -m http.server 8000
# → http://localhost:8000/constellation-rotation/
```
