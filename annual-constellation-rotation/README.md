# 🌌 별자리의 연주 회전 (Annual Rotation of a Constellation)

지구가 **공전**하기 때문에 **같은 시각에 관측하면** 주극성 별자리(**북두칠성**)가
**북극성을 중심으로 한 달에 약 30°씩 반시계 방향으로 회전**하고 1년 뒤 제자리로 돌아오는
모습을 보여주는 교육용 시뮬레이션입니다. 빌드 없이 브라우저에서 바로 동작합니다.

> ⚠️ 기본적으로 **지구의 공전**에 의한 **1년** 변화를 반복합니다. ‘하루 운동 함께 보기’를
> 켜면 **자전**에 의한 하루 동안의 회전도 겹쳐서 보여줍니다.

## 세 가지 뷰 (모두 연동)

| 뷰 | 설명 |
| --- | --- |
| 천구 (바깥에서 본 모습) | 천구에 고정된 북두칠성·북극성과 관측자·지평선. 드래그로 시점 회전. |
| 반구(하늘 돔) — 사람이 가운데 | 관측자를 둘러싼 하늘 돔에서 북두칠성이 북극성을 중심으로 회전. |
| 하늘 평면 — 바라보는 방향 | 선택한 방향(기본 북쪽)을 바라볼 때 보이는 하늘. 북극성 둘레로 도는 모습을 정면에서. |

## 조작

- **관측자 위도** 슬라이더
- **관측 시각**(매일 같은 시각) 슬라이더 — 기본 21시
- **날짜(1년)** 슬라이더 — 연주 회전의 주 축
- **하루 동안의 운동(일주)도 함께 보기** 체크박스 — 켜면 자전에 의한 하루 회전도 겹침
- **바라보는 방향** 버튼(북·동·남·서), 재생/일시정지/정지, 재생 속도
- 모든 슬라이더 값은 숫자를 **클릭하면 직접 입력** 가능

## 모델

지방 항성시 `LST = 태양 적경 + (관측시각 − 12)×15°` 로 두어, 정오에 태양이 남중하고
같은 시각에 날짜가 바뀌면 별이 한 달 약 30°씩 도는 연주 회전과, 시각이 바뀌면 하루
15°/시로 도는 일주운동이 하나의 식으로 일관되게 표현됩니다.
