# ✨ 별들의 일주운동 (Diurnal Motion of Stars)

지구 자전 때문에 하루 동안 별들이 천구의 극을 중심으로 원을 그리며 도는
**일주운동**을 보여주는 교육용 시뮬레이션입니다. 빌드 없이 브라우저에서 바로
동작하는 순수 HTML/CSS/JavaScript(캔버스) 페이지로, 외부 라이브러리가 없습니다.

> ⚠️ 이 시뮬레이션은 **지구의 자전**에 의한 **하루(약 24시간)** 동안의 변화만
> 반복해서 보여줍니다. 지구 공전에 따른 계절 변화나 별의 실제 고유운동·세차운동은
> 포함하지 않습니다.

## 화면 구성

| 영역 | 설명 |
| --- | --- |
| 천구와 지구 (우주 시점) | 천구에 고정된 별과, 자전축을 중심으로 도는 지구·관측자·지평선을 3D로 표시. 마우스로 드래그해 시점을 회전할 수 있습니다. |
| 관측자의 하늘 (반구) | 관측자가 올려다본 하늘. 중심이 천정, 가장자리가 지평선이며, 각 별의 하루 경로(일주 궤적)가 함께 그려집니다. |

## 조작

- **관측자 위치**: 위도(−90°~+90°)·경도(−180°~+180°) 슬라이더
- **시간**: 재생 / 일시정지 / 정지, 경과 시각 슬라이더(0~24h), 재생 속도(0.25×~8×)
- **별 편집**: 세 별(A·B·C)의 적경(RA)·적위(Dec)를 슬라이더로 변경

## 별의 분류 (관측자 위도에 따라 자동 판정)

위도 φ, 적위 δ 일 때:

- **주극성**: 지평선 아래로 지지 않는 별 — `δ ≥ 90° − |φ|` (극과 같은 반구 쪽)
- **전몰성**: 지평선 위로 뜨지 않는 별 — `δ ≤ −(90° − |φ|)` (반대 반구 쪽)
- **출몰성**: 떴다가 지는 별 — 그 사이

위도를 바꾸면 세 별의 분류(주극성/출몰성/전몰성)가 실시간으로 갱신됩니다.

## 참고 천체

- **북극성**(적위 약 +89°): 천구 북극 근처. 북반구에서 방위(북쪽)와 위도를 가늠하는 기준.
- **남십자성**(적위 약 −60°): 천구 남극 방향을 찾는 기준. 남반구에서 주극성이 됩니다.
